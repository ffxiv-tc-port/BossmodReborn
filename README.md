# BossmodReborn

[BossmodReborn](https://github.com/FFXIV-CombatReborn/BossmodReborn) 的台服移植版。戰鬥機制輔助插件：在雷達上畫出場地、敵人與即將到來的危險區，提示機制怎麼處理，並可由 AI 依安全區自動移動與閃避。

## 功能

- **雷達**：螢幕小地圖顯示玩家位置、首領位置、即將到來的各種 AOE 及其他機制，可在「支援的戰鬥」分頁查看並個別啟用支援的首領戰。
- **機制提示**：雷達旁提供即將發生的機制說明、解法提示與個人化建議。
- **AI**：依首領模組判定的安全區域自動移動角色以閃避機制，可與其他插件掛接以自動化整場戰鬥；不建議在與陌生玩家一同遊玩時使用。
- **自動循環**：以最佳能力執行輸出循環，可在「自動循環預設」分頁建立與管理自訂預設。
- **冷卻計劃器**：為支援的首領戰規劃技能施放時機，僅在沒有啟用任何自動循環預設時取代自動循環。
- **深層迷宮**：小地圖、自動走到下層傳送點（傳送石塚等）與寶箱、自動選怪、避開已知陷阱、自動使用魔陶器。
- **任務戰鬥**：部分主線與職業任務的單人戰可以自動執行（設定「啟用任務戰鬥 / 個人副本的自動執行」，預設關）。
- **模組檢視器**：由 Croizat 製作，瀏覽所有支援首領戰的機制模組。

## 指令

- `/bmr`：開啟設定視窗。
- `/bmr ar set <預設名稱>`／`ar toggle <預設名稱>`／`ar clear`：切換或清除自動循環預設。
- `/bmr radar on|off`：開關雷達。
- `/bmrai on|off|toggle`：開關 AI；`/bmrai follow <隊伍位置或名字>` 等子指令調整跟隨對象與距離。

## 分頁

- 設定、支援的戰鬥、自動循環預設、斜線指令、關於。

## 台服版的修改

### 模組、場地與雷達

- 介面繁體中文化（模組、策略與技能名稱用台服官方譯名）。
- 新增多個系列的首領模組：普通難度的 8 人大型任務（亞歷山大機神城、歐米茄時空狹縫、伊甸希望樂園、萬魔殿各系列的大部分場次）、24 人大型任務（失落之都拉巴納斯塔、複製工廠廢墟等）、舊版本的討伐殲滅戰（例：真 俾斯麥殲滅戰、須佐之男殲滅戰、神龍殲滅戰、紅寶石武器破壞作戰、幻 青龍征魂戰），以及多座舊版本的迷宮挑戰（例：紅玉火山獄之蓋、秘本寶庫迦巴勒幻想圖書館、重製後的流沙迷宮樵鳴洞）。
- 既有模組持續修正：沒有讀條或太晚才畫出來的招式提早預告，修正判定時間與場地邊界（例：澤羅姆斯殲滅戰、鬼神祖爾宛殲滅戰、禁忌城邦瑪哈），並補上全體傷害、死刑、打斷與眩暈的提示。部分場地是依錄影與遊戲檔碰撞資料畫的近似場地。
- 沒有專屬模組也有雷達：討伐殲滅戰、大型任務與迷宮挑戰（含首領之間的路上）都會畫出場地、敵人與照讀條猜出的危險區（「沒有專屬模組的討伐戰與大型任務也顯示雷達」「迷宮挑戰沒有載入首領模組時也顯示雷達」，都預設開）。多座迷宮挑戰附整座副本的障礙物圖，雷達畫得出牆壁，AI 尋路也會避開。
- 照讀條猜出來的危險區，在讀條早該結束卻沒結束時會自動清除，不再一直擋住閃避與尋路（「通用危險區逾時清除」，預設開）。
- 雷達上按右鍵可開選單：本場模組設定、停用模組與常用顯示開關。雷達文字跟著 Dalamud 的字型大小縮放，另有「雷達文字大小倍率」；近戰範圍指示可以改畫在目前目標身上（預設關）。

### AI 移動與閃避

- AI 預設在插件載入時自動開啟（跟隨模式）。不想要的話，在 AI 設定關掉「插件載入時自動啟用 AI」，或用 `/bmrai off` 當場關閉。
- 「按住指定鍵暫停自動移動」（預設 Alt，也可以選滑鼠側鍵；只停移動、不停出招）。按著的時候腳下危險區快生效，會在聊天視窗提示一次，並暫時不理會暫停鍵、照常閃避，安全後恢復暫停（兩項都預設開，可關）。
- 尋路改在背景執行緒算，主執行緒每幀負擔變小（路線晚一幀更新）；閃避會預先考慮接下來幾波 AOE。
- AI 開著時，走路來不及閃就改用落點安全的位移技閃避（預設開）。任何來源放出的位移技（包含其他循環插件），落點在危險區內、場地外或離危險區邊緣太近時會被攔下（預設開）。
- 身上有加速度炸彈時，不論副本有沒有專屬模組，AI 與自動循環到期前都會停止移動與出招。
- 選目標：帶無敵狀態的敵人先跳過；限時必殺的小怪（例：泰坦討伐戰的花崗石牢）就算設成不換目標也會切過去打。
- 分隊攻略任務：機制目標沒有分隊員在打時，自動對它下「號令：戰鬥開始」（預設開，可在 AI 設定關）。
- 抑制原地來回抖動的兩個選項：「到點防過衝」與「尋路反轉去抖動」（都預設關）。

### 減傷與循環插件的配合

- 新增「預測減傷」循環模組：在首領模組預告的全體傷害與死刑打到之前，先按減傷與自保的能力技。依危險度分級出手，不按戰技、不改目標，可以和其他循環插件並行。要把它加進循環預設，或開啟「不掛預設集也執行預測減傷」（預設關）才會動作。
- 與 [WrathCombo](https://github.com/ffxiv-tc-port/WrathCombo) 等循環插件配合：詠唱來不及閃時先讓位給 AI 閃避；加速度炸彈這類要停手的機制會通知對方暫停出招；位移技放出前先檢查落點。

### 給其他插件的介面（IPC）

端點名稱都以 `BossMod.` 開頭，除了下面標明的以外都是唯讀查詢。

- **傷害預告**：下一發全體傷害與死刑還有幾秒、危險度（低／中／高）與來源技能，以及「下一發打到自己的死刑」。
- **特殊模式**：即將生效的停手、禁止移動、必須移動等狀態的種類與剩餘時間，讓循環插件跟著停手。
- **打斷與眩暈**：該打斷、該眩暈的目標清單，以及這場戰鬥的打斷／眩暈是否要保留給指定的讀條。
- **限時必殺目標**：模組標記的必殺小怪清單，供自動化插件切目標。
- **位移落點安全**：查詢指定落點、指定位移技會不會把人送進危險區。
- **暫時覆寫**（會改行為）：其他插件（例：AutoDuty、Questionable）暫時切換循環預設或設定時，只在這次遊戲中生效，不改寫你的設定檔。
- **深層迷宮**：這隻怪現在開打會不會一次帶上太多隻；「一般層只標記必要的打斷」此刻有沒有在運作。
- **副本目標進度事件**：即時轉發 DirectorUpdate，[TC Toolbox](https://github.com/ffxiv-tc-port/TCToolbox) 的前線目標面板用它顯示紛爭前線的目標狀態。

### 寶物庫與深層迷宮

- 寶物庫：獎勵怪任何時候都優先於普通怪，曼德拉戰隊照擊殺順序打；首領先倒而獎勵怪還在時模組不提早結束。「寶物庫：目標鎖定獎勵怪」（預設關）開啟後，遊戲目標會鎖在該打的那隻直到倒下。
- 深層迷宮的陷阱與寶藏：內建陷阱資料之外，可結合 PalacePal 的陷阱與「埋藏的寶藏」資料；踩過的陷阱這一層不再閃避。
- 深層迷宮的趕路：可以設定趕路時避開怪物的仇恨範圍（預設關）並多保持一段距離，風箏閃避時也避開其他怪物；去寶箱途中一直卡住就放棄那個寶箱、改去下一個目標；小地圖「走到房間」按鈕與「趕路撞牆時改由 vnavmesh 帶路」（預設關）需要 vnavmesh。
- 深層迷宮的道具：喝藥判斷模組依預估血量決定何時喝藥、挑回復量最多的治療劑（深層迷宮專屬藥水要另外勾選才會自動喝，預設不喝）；魔陶器拿滿時可在適合的時機自動用掉（逐種勾選，預設關）；金寶箱在身邊怪多或血量偏低時先不開。
- 深層迷宮的戰鬥：「一般層只標記必要的打斷」（預設關）把打斷技留給躲不掉的讀條；可在深層迷宮內暫停 WrathCombo 的自動循環（預設關）。

### 穩定性

- 遊戲改版後有特徵碼對不上時，插件照常載入、只停掉相依的功能，並跳通知與在聊天視窗列出缺了哪幾項。例外是會寫入遊戲記憶體的位置：推導不出來時插件寧可不載入，不帶著沒驗證過的位置去寫。
- 設定存檔先寫暫存檔再換名，存到一半當機不會弄壞設定檔；設定檔或循環預設讀取失敗時先把原檔另存一份（`.bad-<時間>`）再允許寫回，讀不懂的地方只影響那一頁設定。
- 重播檔寫到一半中斷（例：遊戲當機）時，中斷處之前的內容照常可以回放；「自動刪除前保留的最大重播數」只刪 BMR 自己錄的重播檔。
- 多處降低記憶體用量。

## 安裝

1. 在遊戲內輸入 `/xlsettings` 開啟「Dalamud 設定」，到「試驗性功能」分頁的「第三方插件倉庫」（Custom Plugin Repositories）貼上
   `https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json`
   勾選啟用後按「儲存變更」。
2. 輸入 `/xlplugins` 開啟「插件管理員」（Plugin Installer），搜尋「Bossmod Reborn」安裝。

請不要安裝上游（國際服）版本，它不是對著台服客戶端做的。

## 搭配的插件（皆為選用）

- [vnavmesh](https://github.com/ffxiv-tc-port/vnavmesh)：深層迷宮小地圖的「走到房間」按鈕與撞牆時的帶路；vnavmesh 正在走路徑時 BMR 的自動走位會讓路。
- [PalacePal](https://github.com/ffxiv-tc-port/PalacePal)：深層迷宮的陷阱與埋藏的寶藏資料補充。
- [WrathCombo](https://github.com/ffxiv-tc-port/WrathCombo)：循環插件連動（詠唱讓位、停手、減傷預告、位移技落點檢查）。
- [AutoDuty](https://github.com/ffxiv-tc-port/AutoDuty)、[Questionable](https://github.com/ffxiv-tc-port/Questionable)：自動跑副本與任務時，會透過上面的介面暫時切換 BMR 的循環預設與設定。
- [TC Toolbox](https://github.com/ffxiv-tc-port/TCToolbox)：前線目標面板讀取 BMR 轉發的副本目標進度事件。
